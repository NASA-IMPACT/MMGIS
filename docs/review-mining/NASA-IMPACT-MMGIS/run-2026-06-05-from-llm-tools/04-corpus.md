> this is the verified, categorized output (phase 4), input to the DRAFT review

## Run summary

- **43 PRs** enumerated (all states).
- **131 comment threads** analyzed: 106 inline, 21 issue-comment, 4 review-summary.
- **91 substantive** lessons kept · **40 discarded** as nits/logistics/praise
  (not silently dropped — see `03-verdicts.jsonl` for the discards).
- **Code-context coverage:** 104/106 inline comments judged on full code windows +
  post-comment diffs; 2 degraded to `partial` (outdated + renamed/empty file); the
  25 non-inline threads have no code anchor by nature.
- **Confidence (substantive):** high 82 · med 6 · low 3.

These are the strongest candidates for "lessons the team values but the harness

## project-alignment (12)

Reuse the core, follow established patterns, and keep ADRs honest.

1. **Use the project's event bus** (eventbus + scoped event id), not custom
   dispatch / `window.dispatchEvent`. _PR#47 (ack), PR#97 (ignored)_ ·
   [47/r3028474719](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3028474719) ·
   [97/r3351682009](https://github.com/NASA-IMPACT/MMGIS/pull/97#discussion_r3351682009)
2. **Plugins are generic & composable — no plugin-specific routes/treatment in the
   core framework.** ⚠ _PR#111 (ignored)_ · [111/r3351200565](https://github.com/NASA-IMPACT/MMGIS/pull/111#discussion_r3351200565)
3. **Extract shared adapters/types/interfaces into a common module**, not duplicated
   per plugin. ⚠ _PR#111 (ignored)_ · [111/r3351227435](https://github.com/NASA-IMPACT/MMGIS/pull/111#discussion_r3351227435)
4. **Organize components by semantic purpose**, not the domain they're used in (a
   Card isn't a `geo/` component). ⚠ _PR#111 (ignored)_ · [111/r3351236096](https://github.com/NASA-IMPACT/MMGIS/pull/111#discussion_r3351236096)
5. **ADRs must be factually accurate** — misstatements about scope/capability
   ("one mission is one dashboard") propagate into implementation assumptions. ⚠
   _PR#112 (ignored)_ · [112/r3363490974](https://github.com/NASA-IMPACT/MMGIS/pull/112#discussion_r3363490974)
6. **Validate stated architectural constraints against real requirements** before
   finalizing an ADR (e.g. a constraint that removes needed asset-upload workflows). ⚠
   _PR#112 (ignored)_ · [112/r3363499597](https://github.com/NASA-IMPACT/MMGIS/pull/112#discussion_r3363499597)
7. **Clarify asset/resource coupling before choosing a strategy** — single-use UUID
   naming vs. a browsable shared repository are different architectures. ⚠
   _PR#111 (ignored)_ · [111/r3350101304](https://github.com/NASA-IMPACT/MMGIS/pull/111#discussion_r3350101304)
8. **Verify new abstractions against prior team decisions** (don't revive a scrapped
   unified-interface idea). ⚠ _PR#75 (ignored)_ · [75/r3202568483](https://github.com/NASA-IMPACT/MMGIS/pull/75#discussion_r3202568483)
9. **Example tools must use standard framework patterns** (React/JSX, not jQuery
   string markup) — they model best practice. ✓ _PR#80 (addressed)_ · [80/r3203167084](https://github.com/NASA-IMPACT/MMGIS/pull/80#discussion_r3203167084)
10. **Document partial-config scope** + raise architectural constraints (static
    schema can't do conditional rendering) before expanding. _PR#57 (ack)_ · [57/r3191172360](https://github.com/NASA-IMPACT/MMGIS/pull/57#discussion_r3191172360)
11. **Document how a new global/pattern relates to existing ones** (`window.mmgis`
    vs `mmgisAPI`) to avoid parallel systems. _PR#13 (unclear)_ · [13/review-3778444838](https://github.com/NASA-IMPACT/MMGIS/pull/13#pullrequestreview-3778444838)
12. **Audit sibling components for consistency** when adding a capability — avoid
    feature silos. _PR#63 (unclear)_ · [63/issuecomment-4308339388](https://github.com/NASA-IMPACT/MMGIS/pull/63#issuecomment-4308339388)

## craftsmanship (53)

Consolidated recurring rules (supporting PRs in parens):

1. **Pair lifecycle operations.** register↔unregister, add↔remove, create↔delete;
   listeners added in `init()` need cleanup in `destroy()` (leaks); keep teardown
   instance-scoped (don't conflate with manager/registry state).
   _PR#47 (addressed ×3), PR#57 (addressed), PR#80 (ack)_ ·
   [47/r3028689812](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3028689812) ·
   [47/r3028797475](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3028797475) ·
   [57/r3191389941](https://github.com/NASA-IMPACT/MMGIS/pull/57#discussion_r3191389941) ·
   [80/r3203799256](https://github.com/NASA-IMPACT/MMGIS/pull/80#discussion_r3203799256)
2. **Names must match behavior.** Challenge `recalculate*` that only emits an event;
   avoid vague `toggle`/`set`/`do`; back with precise JSDoc.
   _PR#35, PR#47 (addressed)_ ·
   [35/r2880269053](https://github.com/NASA-IMPACT/MMGIS/pull/35#discussion_r2880269053) ·
   [47/r3028686801](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3028686801)
3. **DRY** — extract duplicated logic/types/literals into shared helpers/constants;
   consolidate near-identical functions; magic numbers → named module constants.
   _PR#62, PR#63, PR#75 (addressed)_ ·
   [62/r3066773072](https://github.com/NASA-IMPACT/MMGIS/pull/62#discussion_r3066773072) ·
   [63/r3276885325](https://github.com/NASA-IMPACT/MMGIS/pull/63#discussion_r3276885325) ·
   [75/r3147678694](https://github.com/NASA-IMPACT/MMGIS/pull/75#discussion_r3147678694)
4. **Fail loud, not silent.** Throw descriptive errors over silent return; try/catch
   init + surface to user; prevent duplicates instead of just `warn`.
   _PR#47, PR#57, PR#80 (addressed)_ ·
   [47/r3024683451](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3024683451) ·
   [57/r3191464083](https://github.com/NASA-IMPACT/MMGIS/pull/57#discussion_r3191464083) ·
   [80/r3203790266](https://github.com/NASA-IMPACT/MMGIS/pull/80#discussion_r3203790266)
5. **Validate preconditions/inputs explicitly.** Check constrained fields at
   construction (`defaultState ∈ allowedState`); validate external inputs (geojson)
   by schema not just null-check; add explicit checks on enum/engine branches.
   _PR#47 (addressed), PR#75 (ignored ×2)_ ·
   [47/r3028794568](https://github.com/NASA-IMPACT/MMGIS/pull/47#discussion_r3028794568) ·
   [75/r3202466856](https://github.com/NASA-IMPACT/MMGIS/pull/75#discussion_r3202466856) ·
   [75/r3197224108](https://github.com/NASA-IMPACT/MMGIS/pull/75#discussion_r3197224108)
6. **Prefer native/library APIs over custom or wasteful workarounds.** Existing deps
   (d3-color); framework `visible` prop over ref reassignment (avoids rebuild);
   `ResizeObserver` over CSS-coupled `setTimeout`.
   _PR#62 ×2, PR#80 (addressed)_ ·
   [62/r3066527618](https://github.com/NASA-IMPACT/MMGIS/pull/62#discussion_r3066527618) ·
   [62/r3066569223](https://github.com/NASA-IMPACT/MMGIS/pull/62#discussion_r3066569223) ·

7. **Remove dead/no-op code.** Unused "backwards-compat" exports, empty
   destructuring, unused params, orphaned utilities in the wrong module.
   _PR#57 (addressed/ignored), PR#75 (addressed/ignored)_ ·
   [57/r3191298773](https://github.com/NASA-IMPACT/MMGIS/pull/57#discussion_r3191298773) ·
   [75/r3147738513](https://github.com/NASA-IMPACT/MMGIS/pull/75#discussion_r3147738513) ·
